## Примеры использования функций:

+ Модуль aeroplanes содержит функции получения сводных данных по транзакциям:

**greetings() -> str:**
Функция приветствия. В зависимости от текущего времени выбирает тип приветствия.

**get_transactions_total_spent() -> list:**
Выводит суммарную информацию по картам: последние 4 цифры карты; общая сумма расходов; 
кешбэк (1 рубль на каждые 100 рублей). Данные поступают из внешнего файла.

**get_top_transactions() -> list[dict]:**
Выводит топ 5 транзакций по сумме платежа.


+ Модуль utils содержит функции получения сводных данных из внешних источников:

**get_df_from_file(path: str = PATH_TO_DATA) -> pd.DataFrame | None:**
Функция считывания данных из EXCEL-файла в формат DataFrame.
Ссылка на Excel-файл c транзакциями:
[operations.xls](https://docs.google.com/spreadsheets/d/1yXnr282zAMcTkEhIwZFaJlPJvAeZIwvB/edit?usp=sharing&ouid=106765172812768673646&rtpof=true&sd=true)

**currency_conversion() -> list:**
Функция обращается к внешнему API (https://api.apilayer.com/exchangerates_data/convert) 
для получения текущего курса валют из данных в файле "user_settings.json"

**stock_prices_api() -> list | None:**
Функция получения курса акций, указанных в user_settings.json из внешнего API-источника
(https://www.alphavantage.co/query).


+ Модуль services содержит сервисные функции для поиска сводных данных по транзакциям:

**search_description(transactions: list[dict], descript_word: str) -> list:**
Функция для поиска в списке словарей операций по заданной строке.
Возвращает JSON с операциями, у которых в поле 'Категория' или 'Описание' есть строка,
переданная аргументу функции.

**search_by_individual(transactions: list[dict]) -> list:**
Функция для поиска в списке словарей операций которые относятся к переводам физ.лицам.
Возвращает JSON с операциями, у которых в поле 'Категория' - Переводы,
а в описании есть имя и первая буква фамилии с точкой.

+ Модуль reports содержит функции для формирования отчетов:

**report_to_file(file_name=None):**
Функция-декоратор, записывающая в JSON-файл результат-отчет функции.
Декоратор без параметра — записывает данные отчета в файл 'func_name_report.json'.
Декоратор с параметром — принимает имя файла в качестве параметра.

**spending_by_category(transactions: pd.DataFrame,
                         category: str,
                         date: Optional[str] = None) -> pd.DataFrame:**
Функция принимает на вход: DataFrame с транзакциями, название категории,
опциональную дату в формате 'dd.mm.YYYY' Если дата не передана, то берется текущая дата.
Возвращает траты по заданной категории за последние три месяца (от переданной даты).
